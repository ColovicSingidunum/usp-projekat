# KadarGlas

**AI glasovni asistent za video montažu i striming.** Desktop aplikacija koja glasom, na srpskom i engleskom jeziku, upravlja OBS Studiom, DaVinci Resolveom i Premiere Proom.

Projektna dokumentacija za predmet USP, Tim 1.
